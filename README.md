# quant-agent

中低频量化交易策略面板：美股杠杆 ETF 波动率目标、A 股风险调整动量轮动、港股信号策略，以及回测对比与 AI 复盘。

## 功能

- 三套策略：美股（TQQQ 波动率目标 + 趋势闸门 + 跟踪止损）、A 股（风险调整动量周度轮动）、港股（恒指杠杆 ETF 同框架）
- 回测对比：总收益 / 年化 / 最大回撤 / 夏普 / Calmar，逐月 / 逐季 / 逐年相对基准胜率
- 策略参数持久化：持仓比例、波动率目标、趋势闸门 SMA 可在前端修改并保存
- AI 交易指令：多模型并行分析、市场隔离、审计落库
- 行情数据三层兜底：Yahoo 主源 → 新浪 / 腾讯兜底 → 过期缓存救急

## 运行

```bash
pip install -r requirements.txt
python app.py            # 默认端口 8643，可用 QUANT_AGENT_PORT 覆盖
# 或双击 start.bat（Windows）
```

打开 http://127.0.0.1:8643 。

## 目录

- `app.py` FastAPI 服务与接口
- `backend/` 策略、引擎、数据源、回测、AI 顾问
- `static/` 前端页面
- `lab_optimize.py` 策略优化回测实验脚本
- `reports/` 优化与诊断报告
